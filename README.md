# Practical Development Setup: Flutter, Python, MySQL, and VS Code Integration

## Assignment Overview

This repository contains my Practical Development Setup assignment for the Power Learn Project (PLP).

The assignment covers the setup and integration of essential software development tools.

## Tasks Covered

### Task 1: Flutter Development Environment
- Flutter SDK installation and configuration
- Checking the development environment using `flutter doctor`
- Identifying available devices using `flutter devices`
- Understanding hot reload and hot restart

### Task 2: MySQL Database
- Setting up a MySQL development environment
- Creating and managing a school database
- Writing SQL commands to work with database tables

### Task 3: Python Development Environment
- Installing and configuring Python
- Creating and activating a virtual environment
- Managing Python packages

### Task 4: VS Code Integration
- Configuring Visual Studio Code
- Installing relevant development extensions
- Integrating Flutter, Python, and MySQL development tools

## Assignment Documentation

The repository includes the completed assignment in Word and PDF formats, with explanations and supporting evidence.
